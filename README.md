A travel poster for a place that does not exist — drawn entirely in code, no
photographs, no network. `main.ts` writes one 1024×1024 poster to
`/output/entry.png`, deterministically, every run.

## About

A travel poster for an invented destination, built for the make.fun bounty
"The Poster for a Place That Isn't There". One invented place, one landmark,
one clear promise of what a stay there would feel like — the place's name set
into the picture with intent, in a purposeful palette that leads the eye from
the name to the landmark and the horizon.

## The poster

- **One invented place** — a name, a landmark and an atmosphere that belong
  to this poster alone, borrowed from no real destination.
- **Drawn in code** — every sky, sea, cliff and letterform is generated by
  `main.ts`; the committed `poster.png` is the exact output, byte-identical
  on every run.
- **Built to the gate** — `/output/entry.png` is a whole PNG, 1024 by 1024
  pixels, under 1 MiB, produced with no network access.
